# Symbol lists

26 hand-picked lists of Unicode symbols and emoji (680 entries): heart symbols, check marks, arrows,
Roman numerals, Greek letters, legal symbols (™ © ®), bullet points and more. Each entry has the character,
its Unicode name and code point, the HTML entity, the Windows numpad Alt code where one exists, and a link to a
page with copy buttons and typing instructions for Windows, Mac and Linux.

Maintained by [Free Symbols](https://free-symbols.com), a free copy-and-paste symbol library.

## Use it

Straight from a CDN, no install (jsDelivr serves any public GitHub repo):

```js
const res = await fetch("https://cdn.jsdelivr.net/gh/Webika-Ltd/symbol-lists@main/lists/heart-symbols.json");
const { symbols } = await res.json();
console.log(symbols.map((s) => s.symbol).join(" "));
```

```python
import json, urllib.request
url = "https://cdn.jsdelivr.net/gh/Webika-Ltd/symbol-lists@main/all.csv"
print(urllib.request.urlopen(url).read().decode()[:200])
```

## Fields

| Field | Example | Notes |
|---|---|---|
| `symbol` | ™ | The character itself |
| `name` | Trade Mark Sign | Unicode character name |
| `unicode` | U+2122 | Code point |
| `html` | `&#8482;` | Numeric HTML entity |
| `alt_code` | 0153 | Hold Alt and type these digits on the numpad (Windows). Empty when no numpad code exists |
| `url` | https://free-symbols.com/symbols/punctuation/trade-mark-sign | Copy button, meaning and typing instructions |
